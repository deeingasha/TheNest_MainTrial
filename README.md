# TheNestApp

TheNestApp is an Android application designed to ease communication between landlords and tenants, making it simpler to self-manage properties. This project was built as part of my senior year project to showcase my mobile development skills.
## Features

- **Tenant Management**: Easily manage tenant information and communication.
- **Property Management**: Keep track of property details and maintenance requests.
- **Notifications**: Receive real-time notifications for important updates.

## Installation

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/deeingasha/TheNest_MainTrial.git
2.  **Open the project in Android Studio.**
3.  **Build the project** to download all necessary dependencies.
4.  **Run the app** on an emulator or a physical device.

Usage
-----

1.  **Sign up or log in** to your account.
2.  **Add properties** and manage tenant information.
3.  **Track maintenance requests** and updates.
